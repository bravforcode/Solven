# Demo Script — Solven (≤5 นาที)

> เป้าหมาย: แสดง (1) ปัญหาครู → (2) การกระทำ → (3) AI ประมวลผล → (4) ครูตรวจ/แก้ → (5) ผลลัพธ์จริง → (6) ผลกระทบ → (7) แผนขยายผล
> โหมด: **demo mode** (`NEXT_PUBLIC_SOLVEN_MODE=demo`) — ไม่ต้องใช้ API key จริง

## เตรียมก่อนขึ้นเวที

1. Deploy ล่าสุด + `POST /api/demo/seed` (หน้าเว็บกดปุ่ม Demo seed) — ข้อมูล 10 drafts ทุกสถานะ
2. เปิดหน้าจอ 2 จอ (mobile view + desktop) ถ้าได้
3. เตรียม fallback: ดู `docs/demo-fallback.md` ถ้าเน็ต/API ล่ม

## สคริปต์ (พูดภาษาไทยตลอด)

### บทที่ 1 — ปัญหา (30 วินาที)
> "ครูไทยในโรงเรียนขนาดเล็ก 12,000 แห่งต้องสอนหลายวิชา หลายชั้น ตรวจงานเป็นชั่วโมง ทำเอกสารปลายเทอมทับช่วงสอน AI ช่วยได้ แต่ต้องปลอดภัยและครูเป็นคนตัดสินใจ"

### บทที่ 2 — ตรวจงาน (60 วินาที)
1. เปิดหน้า Create → เลือก **Grading & Feedback**
2. วางคำตอบนักเรียนตัวอย่าง + rubric ที่ครูกำหนดเอง
3. กดสร้าง → ระบบแสดงผล **แบบร่าง** พร้อมคะแนน + feedback รายคน (ภาษาไทย)
4. ชี้ **warning badge** (PII/grounding) และปุ่มแก้ไข — "AI ผิดได้ ครูแก้ก่อนใช้เสมอ"

### บทที่ 3 — แผนการสอน (45 วินาที)
1. เลือก **Lesson-Plan** → ใส่หัวข้อ/ชั้น/จำนวนนักเรียน/เวลา
2. กดสร้าง → ร่างแผน 50 นาที → แก้ 1 จุด → **อนุมัติ**

### บทที่ 4 — เอกสารออกจริง (60 วินาที)
1. Queue → เลือก draft → ปุ่ม **สร้างเอกสาร** (Document Studio)
2. เลือก template (บันทึกหลังสอน/จดหมายราชการ/เกียรติบัตร) → กรอกข้อมูลโรงเรียน
3. **Export PDF** (ฟอนต์ไทยจริง) — "เอกสารพร้อมส่งผู้บริหาร/ผู้ปกครอง"

### บทที่ 5 — ไว้ใจได้ (45 วินาที)
1. เปิด **Audit** — ทุก agent call มีบันทึก (model, latency, guardrail pass/fail, hash)
2. แสดงโหมด offline: ปิดเน็ต → ทำงานต่อ → เปิดเน็ต → queue sync อัตโนมัติ
3. กล่าว PDPA: ข้อมูลนักเรียนถูก redact ก่อนส่ง LLM, ลบตาม retention 180 วัน

### บทที่ 6 — ผลกระทบ + ขยายผล (30 วินาที)
> "คืนเวลาให้ครู ตรวจงานจากชั่วโมงเป็นนาที เริ่มจากโรงเรียนนำร่อง → NDLP → AIS Cloud สำหรับ Thai LLM self-host ตามแผน"

## จุดที่กรรมการมักจี้ (เตรียมตอบ)

| คำถาม | คำตอบที่เตรียมไว้ |
|---|---|
| AI ผิดทำไม | human-in-the-loop + guardrail + quarantine + audit |
| ข้อมูลนักเรียนปลอดภัยไหม | redact ก่อนส่ง LLM, ไม่เก็บ PII จริง, retention policy, เป้า self-host ในไทย |
| ต่างจาก ChatGPT ยังไง | workflow ของครู + rubric + เอกสารราชการ + offline + audit ไม่ใช่ chat |
| วัดผลได้จริงไหม | อ้าง World Bank (+15% เมื่อลดภาระครู), TALIS 29% เวลาธุรการ |
| สเกลได้ไหม | Postgres + org multi-tenant + quota + Thai LLM self-host (ADR-013) |
