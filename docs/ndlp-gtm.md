# แผนเปลี่ยนเป้าหมายการขยายผล: LearnDi → NDLP / ระบบนิเวศ AIS

> สรุปจากการวิจัย 14 ส.ค. 2569 (subagent researcher) — เขียนเพื่อแก้จุดอ่อนเรื่องการอ้าง integration ที่ผิดเป้าผู้ใช้ในใบสมัคร JUMP THAILAND 2026
> สถานะ: **ร่างสำหรับเขียนลงใบสมัคร/สไลด์** — ตัวเลขบางส่วนต้อง re-verify ก่อนส่ง (ดู §4)

## 1. บริบทที่ค้นพบ (อิงแหล่งอ้างอิง)
- **AIS LearnDi** = แพลตฟอร์ม upskilling สำหรับองค์กร/ผู้ใหญ่ (ดำเนินโดย LearnDi Co. สังกัด AIS) — **ไม่ใช่ K-12 และไม่มีหลักฐานว่า MOE/สพฐ ใช้**
- **ช่องทาง K-12 ของรัฐที่แท้จริง = NDLP** (National Digital Learning Platform) โดย MOE + MHESI + Microsoft
- โครงการ **"AI for Teachers"** (MOE/OVEC/IPST/ETDA + Microsoft) ฝึกครูไปแล้ว **160,507 คน** (Oct 2025–Mar 2026)
- AIS มีระบบนิเวศ **AIS AISpace** สำหรับ AI — เป็นช่องทาง AIS ที่ตรงโจทย์มากกว่า LearnDi

## 2. ทำไมต้องเปลี่ยน (เหตุผลเชิงกลยุทธ์)
- กลุ่มเป้าหมาย Solven คือ **ครูสพฐ ในโรงเรียนขนาดเล็ก** — กลุ่มนี้ใช้ NDLP ไม่ใช้ LearnDi
- การอ้าง "integrate เข้า LearnDi (ฐานผู้ใช้ครูที่มีอยู่แล้ว)" เป็น **ข้ออ้างที่ผิดเป้า** → กรรมการที่เข้าใจบริบทการศึกษาไทยจะจับได้ทันที และลดความน่าเชื่อถือ
- NDLP มีฐานครูในระบบรัฐหลักแสนคน + โครงการ AI for Teachers ที่เริ่มแล้ว → เป็นช่องทาง adopt จริงที่อ้างได้ตรงไปตรงมา

## 3. แผนขยายผล 3 ระยะ (ปรับจาก Appendix A.12)
| ระยะ | ช่วงเวลา | เป้าหมาย | วัดผล |
|---|---|---|---|
| **P1 — Pilot** | เดือน 1-4 | 10-20 โรงเรียนขนาดเล็ก ผ่านเครือข่าย สพฐ./NIA/กองทุนความเสมอภาคฯ | ชั่วโมงครูที่ประหยัด, Kappa rubric, satisfaction |
| **P2 — District** | เดือน 5-12 | ขยายสู่เขตพื้นที่การศึกษา 3-5 เขต (~1,000 ครู) | อัตรา adoption รายสัปดาห์, เวลาตอบสนองผู้ปกครอง |
| **P3 — Scale ผ่าน NDLP / ระบบนิเวศ AIS** | ปี 2 | Integrate เป็นโมดูลใน **NDLP** (ฐานครูสพฐ ที่มีอยู่แล้ว) และ/หรือวางเป็นเลเยอร์ครูใน **AIS AISpace** (LearnDi คงเป็นช่องทางองค์กรเสริม ไม่ใช่ core) + ประเมินขยาย IoT (NB-IoT/Magellan) | จำนวนครู active, ผลสำรวจภาระงาน, (ระยะยาว) ผลสัมฤทธิ์นักเรียน |

## 4. ความเสี่ยงที่ต้องเช็คก่อนอ้างในใบสมัคร (ห้ามเดา)

- [ ] กระบวนการอนุมัติ/ความปลอดภัยสำหรับระบบที่แตะข้อมูลนักเรียนใน NDLP
